# 需求质量快速检查清单

## 可测试性检查

- [ ] 每个功能是否有明确的验收标准？
- [ ] 验收标准是否可量化？
- [ ] 输入数据的范围和格式是否明确？
- [ ] 输出结果是否明确定义？
- [ ] 是否有明确的成功/失败判断条件？

## 完整性检查

- [ ] 是否有前置条件说明？
- [ ] 正常流程是否完整？
- [ ] 异常/错误场景是否覆盖？
- [ ] 边界条件是否说明（最大值、最小值、空值）？
- [ ] 不同数据状态下的行为是否说明？

## 清晰性检查

- [ ] 术语是否有定义或解释？
- [ ] 是否避免了模糊词（"等"、"可能"、"约"）？
- [ ] 每句话是否只有一个含义？
- [ ] 复杂流程是否有配图？

## 一致性检查

- [ ] 同一概念是否使用同一术语？
- [ ] 不同章节对同一流程的描述是否一致？
- [ ] 数据字段定义是否前后一致？

## 可追溯性检查

- [ ] 需求是否有唯一编号？
- [ ] 是否关联业务需求/用户故事？
- [ ] 是否有版本和修订记录？

## 可实现性检查

- [ ] 是否有明显技术障碍？
- [ ] 性能要求是否现实？
- [ ] 是否依赖未确定的技术或系统？
