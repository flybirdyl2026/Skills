# 测试用例格式规范

## 一、输出测试用例结构

### 1.1 列结构（9列，当前格式）

| 列 | 字段 | 说明 |
|----|------|------|
| A | 需求编号 | 功能点编码，如 `F_UC_A_YHGL_YHLB_W1`，从需求文档括号中提取 |
| B | 用例编号 | `CS-{前缀}-{序号}`，每模块内从 001 重新编号 |
| C | 用例等级 | P0 / P1 / P2 / P3 |
| D | 用例标题 | **模块行**=完整模块路径（含章节号与编码，用 `-` 分隔）；**用例行**=用例名称 |
| E | 预置条件 | 测试前需满足的条件（自动去旧编号，换行） |
| F | 操作步骤 | 详细操作步骤（自动去旧编号，加 `1. 2. 3. ` 序号，换行） |
| G | 预期结果 | 预期输出（自动去旧编号，加 `1. 2. 3. ` 序号，换行） |
| H | 执行结果 | 默认空，测试执行后填写（通过/失败/阻塞） |
| I | 备注 | ⚠️ 传入 `--summary` 后，P0/P1 问题及改进建议自动写入此列 |

> ⚠️ **重要**：本 skill 经历过一次重大格式升级（v1→v2），9列格式为当前标准，
> `需求编号` 列是 v2 新增的，用例编号前缀与需求编号中编码对应。
> 若旧版用例是8列格式，用 Excel/VBA 将第一列重命名为"需求编号"即可对齐。

### 1.2 用例编号规则

```
格式：CS-{前缀}-{序号3位}
规则：每个模块独立编号，模块切换时从 001 重新开始

示例：
  模块：用户管理 > 查看用户列表（F_UC_A_YHGL_YHLB）
    → CS-YHLB-001 ~ CS-YHLB-017
  模块：用户管理 > 查看用户详情（F_UC_A_YHGL_YHXQ）
    → CS-YHXQ-001 ~ CS-YHXQ-010
  模块：订单管理 > 创建订单（F_UC_A_DDGL_CJDD）
    → CS-CJDD-001 ~ CS-CJDD-010
```

**前缀提取算法（`_extract_module_prefix()`）：**

```
输入示例：模块路径
  订单管理 > 创建订单 > 填写订单信息（F_UC_A_DDGL_CJDD）

处理步骤：
  1. 从路径中提取所有括号内编码（支持中文括号（）和英文括号()）
  2. 取最后一个编码（最细粒度子级）→ F_UC_A_DDGL_CJDD
  3. 去掉前导框架前缀（F_UC_B_）→ DDGL_CJDD
  4. 提取 W\d 后缀（如有）→ W1 等
  5. 去掉 W\d 后缀，取末段拼音 → CJDD
  6. 防重检查：若前缀已使用，追加 W\d 后缀区分

防重规则（关键）：
  如果末级子模块拼音相同，则追加 W\d 后缀确保编号唯一。

示例：
  F_UC_A_DDGL_SQ_W1（PC申请）→ 基础前缀 SQ → 首次使用 → SQ
  F_UC_A_DDGL_SQ_W2（移动申请）→ 基础前缀 SQ → 已重复 → 追加W2 → SQW2
  F_UC_A_DDGL_SQ_W3（其他申请）→ 基础前缀 SQ → 已重复 → 追加W3 → SQW3

  结果：
    PC申请模块：CS-SQ-001 ~ CS-SQ-010
    移动申请模块：CS-SQW2-001 ~ CS-SQW2-008
    其他申请模块：CS-SQW3-001 ~ CS-SQW3-005
```

**编号重置规则：**

| 场景 | 编号行为 |
|------|---------|
| 同一模块内 | 连续递增（001→002→003...） |
| 模块切换时 | 重置为 001，前缀更新为新模块的子级拼音 |
| 全局 | 不保证唯一（允许不同模块出现相同序号，如 CS-SJLB-001 和 CS-SJXQ-001） |

### 1.2.1 模块行显示规则

```
格式：父级模块 - 当前模块（编码）
示例：
  4.3 用户管理功能（UC_A_YHGL）描述 - 4.3.2.1. 用户列表功能

规则：
  - 完整层级路径，用 `-` 连接各层级标题（v2 起从 `>` 改为 `-`）
  - 最末级保留括号内的功能点编码
  - 不对 `-` 符号做XML转义（Excel单元格直接支持）
```

### 1.3 操作步骤 & 预期结果编号逻辑

LLM 返回的步骤/预期结果可能含旧编号（如 `"1. xxx"`），或为单行分号分隔文本。
脚本自动处理后统一输出为 `1. 2. 3. ` 格式，换行显示。

**处理策略（`scripts/generate_cases.py` 中的内联逻辑）：**

```
操作步骤：
  0. 先把字面量 \\n 替换为真正的换行符 \n

  1. 取 steps[] 列表每项
  2. 去旧编号（r'^\d+[.)、\s]+' + r'^\d+[)）]\s*'）
  3. 重新加 1. 2. 3. 前缀，\n 换行

前置条件：
  0. 先把字面量 \\n 替换为真正的换行符 \n

  1. 按 \n / ; / ； 分割原始文本
  2. 每段去旧编号（同上正则）
  3. 重新加 1. 2. 3. 前缀，\n 换行

预期结果：
  0. 先把字面量 \\n（反斜杠+n两个字符）替换为真正的换行符 \n

  1. 按 \n / ; / ； 分割原始文本
  2. 每段去旧编号（同上正则）
  3. 重新加 1. 2. 3. 前缀，\n 换行

示例：
  LLM原始操作步骤：["1. 点击发布按钮", "2. 填写表单内容"]
  处理后：
    1. 点击发布按钮
    2. 填写表单内容

  LLM原始预期结果：1. 左侧显示发布通知列表页面;2. 右侧默认显示空白页
  处理后：
    1. 左侧显示发布通知列表页面
    2. 右侧默认显示空白页
```

### 1.4 视觉效果

| 位置 | 底色 | 自动换行 | 字体 |
|------|------|---------|------|
| 表头行 | 深蓝 #4472C4 | ✅ 开启 | 白字粗体 |
| 模块行 | 浅蓝 #DCE6F1 | ❌ 关闭（标题不自动换行） | 深蓝粗体 |
| 用例行 | 无（透明 #000000） | ✅ 开启 | 正常 |
| 用例编号 | 无（透明） | ✅ 开启 | 正常 |
| 备注列 | 无 | ✅ 开启 | 正常 |

**重要：**
- 模块行 `wrap_text=False`：避免标题超长时 Excel 自动折行导致行高异常
- 用例编号列无底色：纯色底与白色背景的对比最清晰，编号更醒目
- 用例编号在 A 列水平居中，其他列左对齐

## 二、模块名提取规则

### 2.1 完整层级路径

模块名采用**完整层级路径**展示，用 `>` 连接各层级标题：

```
格式：父级模块 > 当前模块（编码）

示例：
  4.3 用户管理功能模块（F_UC_A_YHGL） > 4.3.2.1 用户列表功能点(F_UC_A_YHGL_YHLB)
  订单管理 > 创建订单 > 填写订单信息（F_UC_A_DDGL_CJDD）
```

**规则：**
- 从文档标题层级中提取所有有效模块标题
- 用 `>` 连接，保留章节号与功能点编码
- 最末级保留括号内的功能点编码

### 2.2 段落标题过滤（黑名单）

文档中的**段落标题**（如"功能点划分"、"业务处理流程及业务逻辑"）不属于模块层级，应被过滤掉。

**过滤关键词列表（`_is_content_section()` 函数）：**

```python
KEYWORDS = [
    '处理流程', '业务逻辑', '业务规则',
    '原型界面', '界面说明', '界面设计', '界面原型',
    '数据要求', '数据字典', '非功能需求', '数据结构',
    '接口说明', '接口设计',
    '流程说明', '流程描述',
    '状态说明', '状态转换', '状态机',
    '备注说明', '补充说明', '其他说明',
    '约束条件', '前提条件', '异常处理',
    '性能要求', '安全要求',
    '功能点划分', '功能描述', '功能说明', '功能概述',
    '需求描述', '总体描述', '概述', '总则',
    '功能需求模型', '项目功能需求',
]
```

**过滤逻辑：**

```
对每个标题文本：
  1. 检查是否包含上述关键词
  2. 若包含 → 过滤掉（不计入模块层级）
  3. 若不含 → 保留为有效模块标题
```

**示例：**

```
文档标题层级：
  L1: 4 项目功能需求模型描述          → FILTERED by [功能需求模型]
  L2: 4.3 用户管理功能模块（F_UC_A_YHGL）  → KEPT
  L3: 4.3.2 功能点划分                 → FILTERED by [功能点划分]
  L4: 4.3.2.1 用户列表功能点(F_UC_A_YHGL_YHLB)  → KEPT
  L5: 业务处理流程及业务逻辑           → FILTERED by [业务处理]

最终模块名：
  4.3 用户管理功能模块（F_UC_A_YHGL） > 4.3.2.1 用户列表功能点(F_UC_A_YHGL_YHLB)
```

### 2.3 实现位置

- 过滤函数：`_is_content_section(title_text)`
- 关键代码：`filtered_levels = [l for l in sorted_levels if not _is_content_section(heading_map[l])[0]]`
